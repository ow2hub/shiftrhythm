# チャンネル改善リサーチ（2026-11-24）

データ元: vidIQ（channel_search / outliers / keyword_research を 2026-11-24 に取得）、Web検索、10/5時点の YouTube Studio スクリーンショット。
※ vidIQ に接続されているのは「Mochi Did It」だけなので、本のデータ研究所の非公開アナリティクスは取れていない。

## 結論

- 「本のデータ研究所」の企画（目次の集計・AI実験）は**停止を推奨**。検索する人がいない、1本の手間が大きすぎる、結果も出ていない。
- 乗り換え先の第一候補: **大人〜シニア向け「脳トレ」ショート**（都道府県・漢字・ひらがなのパズル）。2026年に開設したチャンネルが数か月で数百万〜1億回再生まで伸びている。
- 問題はプログラムで自動生成でき、正解のチェックも自動でできる。作業は「コマンド1回＋まとめてアップロード」だけになる。

## 1. 今のチャンネルの診断（9/07〜10/04の28日間）

| 指標 | 値 |
|---|---|
| 視聴回数 | 197（うちショート 190） |
| 総再生時間 | 0.1時間 |
| 登録者の増加 | ほぼ0 |
| ショートの「視聴を継続」 | 10%（90%がスワイプ） |
| 長尺1本あたりの再生 | 約7回 |

原因:
1. **誰も検索しないテーマ**（「本の目次を数えた」）→ 長尺が検索にもおすすめにも出ない
2. **理解に説明が必要**（目次・主張・見本…）→ ショートの最初の1秒で離脱
3. **手間が大きすぎる**（目次集め → AIに3回 → 集計 → 台本 → 書き出し）→ 投稿は月3本程度
4. **カスタムサムネイルが使えない**（電話番号の上限）→ 長尺はさらに不利。ショートには影響なし
5. **誰向けかが曖昧**（読書好き？AI好き？データ好き？）

## 2. 伸びているチャンネルの調査

### 顔出しなし・日本語・2025年6月以降に開設・ブレイク中（登録者の30日伸び率順）
- 上位はアニメ／映画の切り抜き、中国ショートドラマの転載、おもちゃ、海外動画の翻訳。
  → 他人の映像が必要で、著作権と「再利用コンテンツ」のリスクがあるため不採用。
- オリジナルで伸びているのは「仕組み解説（建機・トラック・土木）」系（例: みちけんきゅうじょ、2026/1開設→1.73万人）。映像素材が必要で手間が大きい。

### 小さいチャンネル（登録1万人以下）で今月バズったショート
- VTuber切り抜き、2ch、占いランキング（登録2,200人で51万回）、皇室・芸能、家族ドラマの寸劇、コスメ。
  → 切り抜きは素材が必要。占い・ゴシップは信頼性と価値の面で不採用。

## 3. 浅い市場か？

- 正直に言うと「誰もいない市場」ではない。2026年は参入ラッシュの最中。
- ただし、8〜9月に開設したチャンネルが2〜3か月で数百万回まで伸びている ＝ **まだ需要が供給を上回っている**。
- 検索は減り気味なので、いずれ飽和する。入るなら早いほど有利。
- 差別化できる点: ほとんどが無音（BGM＋文字）。
  1. キャラクターの声で問題を読み上げる（文字を読むのがつらい人にも）
  2. プログラムで正解をチェックするので間違いがない
  3. 形式の種類を多くする

## 4. 新しい方針（案）

- **チャンネル**: 今のチャンネルを改名して使う（登録者がほぼ0なので失うものがない。本の動画は限定公開にする）。名前の例:「ノアとメイの脳トレ」
- **主力**: 10〜15秒・1問のショートを1日3本（7時・12時・18時に予約投稿）
- **形式**（すべて自動生成し、正解も自動でチェック）:
  1. 漢字マス（4×4）に隠れた都道府県
  2. ひらがなを並べ替えると都道府県
  3. 「お□□□」で始まる都道府県は？
  4. 県庁所在地の3択
  5. 計算・マッチ棒（数字なので検証が確実）
- **流れ**: 0秒で問題を表示しノアが読み上げ → 5秒カウントダウン → 正解でピンポン → メイ先生の一言 → 最初に戻ってループ
- **長尺**（余裕があれば週1本）: 20問まとめ（8〜10分）。テレビで流す人向け
- **手間**: 週1回「コマンド1回で21本を出力」→ Studioでまとめてアップ＆予約（20〜30分）

## 5. リスクと対策

- **収益化審査の「繰り返しの多いコンテンツ」**: テンプレートを使い回し、解説がない動画は不利。
  → 形式を5種類以上で回す。正解の後に一言の解説（豆知識）を入れる。キャラクターの掛け合いで独自性を出す。
- **健康についての主張**: AIで作ったキャラクターが健康の効果を語るのは要注意。
  → 「認知症予防に効く」とは言わない。「頭の体操」「ひらめきクイズ」と表現し、概要欄に「医療的な効果を保証するものではありません」と書く。
- **反応が薄い**（高評価率0.2〜0.6%）→ 登録者は増えにくい。判断は再生数で行う。
- **飽和** → 2週間（約40本）で平均再生を見て、伸びなければ形式を変える。

## 6. 判断の目安（2週間後）
