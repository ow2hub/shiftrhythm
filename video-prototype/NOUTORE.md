# 脳トレショートの作り方

## 最初に1回だけ
1. チャンネル名を変える（例:「ノアとメイの脳トレ」）
2. 本の動画は「限定公開」にする
3. YouTube Studio → 設定 → アップロード動画のデフォルト設定 → 説明 に、
   `アップロード手順.txt` の下半分（概要欄）を貼る

## 毎週やること（20〜30分）
1. VOICEVOX を起動する
2. ターミナルで:
   ```
   cd ~/ow2-guide/video-prototype
   git pull
   python3 noutore.py --count 21 --start 2026-12-01
   ```
   （`--start` は最初に投稿する日。2週目以降は次の月曜などに変える）
3. `build/noutore/<日付>/` に21本できる。ファイル名がそのままタイトルになる
4. Studio →「作成」→「動画をアップロード」で15本ずつ選ぶ
5. 1本ずつ「公開予約」にして、`アップロード手順.txt` の日時を入れる

見本だけ作るとき: `python3 noutore.py --sample`

## 伸ばすための工夫（ツールに入っているもの）
| 工夫 | なぜ |
|---|---|
| 0秒で問題が出ている（タイトル画面なし） | 最初の1〜2秒でスワイプされるかが決まる |
| 1本10〜14秒・1問だけ | 伸びている脳トレショートは6〜17秒 |
| 5秒のカウントダウン＋時計の音、残り3秒で赤く | 「間に合うか」で最後まで見てもらう |
| 半分でヒント（光るマス・選択肢を1つ消す） | わからない人も離れない |
| 正解でピンポン・紙ふぶき・キャラが跳ねる | 「わかった！」の気持ちよさ |
| 最後に「何秒でわかった？」→ 最初の画面に戻る | コメントとループ再生が増える |
| 決めゼリフ・タイトルは数パターンから選ぶ | 毎回同じだと収益化審査で不利 |
| 7時は漢字マス・12時はならべかえ／頭文字・18時は県庁所在地 | 時間ごとに形式を固定すると習慣になる |
| 問題はプログラムで作り、正解も自動でチェック | 答えが2つある・読みが違う、を防ぐ |

## 比べて決める（2週間ごと）
- 声: いつもは `--voice A`（テンポよく）。2週目は `--voice B`（ゆっくり・やわらかめ）で作る
- BGM: なしで試すときは `--no-bgm`
- 見る数字: 各ショートのアナリティクスにある **「視聴を継続」の割合**（目安 60%以上）と再生回数
- 一度に変えるのは1つだけ。勝った方を残す

## 声を別のキャラに変えるとき
`noutore.py` の `VOICE_SETS` にある名前とスタイルを書き換える（例: ずんだもん / ノーマル）。
そのキャラの利用規約を確認し、概要欄のクレジット（`CREDITS`）も書き換えること。
