## この回の核になる主張

> AI活用本11冊で最も多く勧められていたのは「出力の見本を示す」(4/11)。
> **そしてTOP10のうち5個が、使い道ではなく「頼み方」の話だった。**
> 使い道は本ごとの専門領域でバラバラ(62種類が1冊だけ)。
> SEOの本はSEOの話、発想法の本は発想法の話をしていただけ。
> **使い道はあなたの仕事で決まる。本から学ぶべきは、頼み方。**

### TOP10の内訳(頼み方 5 / 使い道 5)

**頼み方**: 出力の見本を示す(4) / AIに役割を与える(3) / AIに逆質問させる(2) /
効果的なプロンプトを作る(2) / 指示を具体的にする(2) — **上位に固まっている**

**使い道**: AIで営業する(2) / AIを学ぶ(2) / 低単価案件で実績を作る(2) /
文章を校正する(2) / 文章を要約する(2) — **最多でも2冊止まり**

### 1冊にしかない62個の正体

| 本 | その本だけの主張 |
|---|---|
| SEO×生成AI | 検索意図を調べる / 競合キーワードを調べる / サイト構造を整理する など6個 |
| AIを使って考えるための全技術 | 悩みを分割する / 異質な要素を取り入れる / 専門家の視点で考える など6個 |
| ChatGPT×資料作成術 | 議事録を作る / 会議アジェンダを作る / 報告書の骨子を作る など4個 |

**どの本も、自分の専門の話をしていただけ。** だから使い道は重ならない。
