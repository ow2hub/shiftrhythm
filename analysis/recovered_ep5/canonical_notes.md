# 第5回の名寄せ表について

206表現 → **130種類**(85件を統合 / 統合率 **41%**)。

## 統合率が過去より高い理由

| 回 | 表現数 | 統合後 | 統合率 |
|---|---|---|---|
| 第2回(時間術) | 179 | 124 | 33% |
| 第3回(読書術) | 124 | 80 | 35% |
| **第5回(AI活用)** | **206** | **130** | **41%** |

基準を緩めたわけではない。**AI本は「道具の名前が入るかどうか」だけが違う表現が大量に出る**ため。

- 「ChatGPTで文章を作る」/「文章作成に活用する」
- 「議事録をAIで作る」/「議事録を作る」
- 「会議アジェンダをAIで作る」/「会議アジェンダを作る」

これらは同じ行動を、ツール名ありとなしで書いただけ。むしろ第2回・第3回の統合より
機械的で、判断が入る余地が小さい。**統合率が上がったこと自体が、このジャンルの特徴。**

## 分けたままにしたもの

| 分けたもの | 理由 |
|---|---|
| 指示を具体的にする / **6W3Hで具体化する** | 後者は具体的な枠組みを指定した別の主張 |
| 情報収集に活用する / Deep Researchで調査する / Web検索で最新情報を調べる | 使う機能が違う |
| 単純作業を自動化する / **GPTsで作業を自動化する** / タスク機能で通知を自動化する | 手段が別 |
| 一度に1つ質問する / **1チャット1テーマにする** | 質問の数と、会話の単位は別 |
| 課題の原因を抽出する / 悩みの原因を探る | 仕事の課題と個人の悩みで扱いが違う |
| 事前に情報を与える / 過去の文章を読み込ませる | 後者は具体的な入力物を指定している |
| まずやってみる / 悩んだらやってみる / 生成AIを使ってみる | 迷ったときの話かどうかが違う |
| 目標を設定する / 目標達成プランを作る / 行動計画を作る / 導入計画を作る | 作る物が違う |
| AI利用のリスクを確認する / **誤情報への対策をする** | 後者は具体的な対策行動 |

**ここを緩くすると「共通点が多い」という結論を作れてしまう。**
第2回・第3回と同じく、迷ったものは統合しない側に倒した。
