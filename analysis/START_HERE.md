# これをやってください(30冊分析の手順)

このファイルの通りに上から順にやれば、動画に入れる数字が出ます。
**プログラムの知識は不要です。** コピペと、コマンドを3回打つだけです。

作業は途中で何日か空いても大丈夫です。ファイルに保存されていくので消えません。

---

## 準備(5分)

ターミナルを開いて、このフォルダに移動します。

```bash
cd ~/ow2-guide/analysis
```

※ `~/ow2-guide` の部分は、リポジトリを置いた場所に読み替えてください。

動くか確認します。

```bash
python3 make_dummy.py
python3 aggregate.py --dir dummy
```

「トップ3:」まで表示されればOKです。これはダミーでの練習なので、結果は無視して構いません。

---

## STEP 1 — 30冊を選ぶ(30分)

Amazonで「時間術」または「仕事術」のカテゴリを開き、**売れ筋ランキングの上から順に30冊**メモします。

> 好きな本を選ばないでください。上から機械的に取ります。
> ここで選り好みすると、結論が最初から歪みます。動画でもそう宣言しています。

`books.sample.csv` をコピーして `books.csv` を作り、30行書きます。

```bash
cp books.sample.csv books.csv
open -e books.csv        # テキストエディットで開く
```

こんな形式です。**1行目はそのまま残してください。**

```
id,title,author,year,origin
b01,エッセンシャル思考,グレッグ・マキューン,2014,洋書
b02,鬼速PDCA,冨田和成,2016,和書
b03,...
```

- `id` は `b01` から順に、必ず連番で
  ※本を足し引きして番号が飛んだら `python3 check_books.py --renumber` で振り直せる
- `origin` は翻訳書なら `洋書`、日本人が書いた本なら `和書`
- `year` がわからなければ適当で構いません(集計には使いません)

## STEP 2 — 各本の情報を集める(1.5〜2時間)← ここが一番時間かかります

冊数ぶんのテキストファイルを作ります。

```bash
python3 check_books.py --init
```

books.csv に書いた冊数ぶんだけ、入力用ファイルが `books/` にできます。
すでにあるファイルは上書きしないので、何度実行しても安全です。

`books/b01.md` から順に開いて、Amazonの商品ページから以下を貼り付けます。

```bash
open -e books/b01.md
```

貼り付けるもの:

1. **内容紹介 / 商品の説明** — 商品ページの説明文をそのままコピペ
2. **目次** — 「なか見!検索」か、出版社サイト、honto、楽天ブックスなどに載っています
3. **読んだ本なら自分のメモ** — 読んでいなければ空欄でOK

> **本文はコピーしないでください。** 使っていいのは目次・公開されている紹介文・自分の言葉のメモだけです。
> 動画の中でもそう宣言していますし、著作権上もここが線引きになります。

1冊3〜4分です。15冊なら1時間ほど。**ここがこの企画の本体です。**
音楽でもかけながら淡々とやってください。

### 目次だけをまとめて貼りたいとき

15冊ぶんのファイルを1つずつ開くのが面倒なら、目次は1枚のシートにまとめて貼れる。

```bash
python3 paste_tocs.py --init    # tocs.md ができる(見出しだけ入っている)
open -e tocs.md                 # 各見出しの下に目次を貼る
python3 paste_tocs.py           # books/*.md の「## 目次」に流し込む
```

途中まででも構わない。貼っていない本は飛ばされるので、何日かに分けて進めてよい。
既に目次が入っている本は上書きしない(`--force` を付けたときだけ上書きする)。

全部書き終えたら、抜けがないか確認します。

```bash
python3 check_books.py
```

1冊ずつ「目次◯行/◯字」と表示されます。「中身が入っていません」と出たものだけ埋めれば完了です。

## STEP 3 — AIに投げる(30分)

プロンプトを自動で組み立てます。

```bash
python3 make_prompts.py
```

`prompts_out/` にプロンプトができます(冊数とバッチサイズで個数が決まります)。

紹介文だけで分析する場合は、全冊まとめて1回で投げられます:

```bash
python3 make_prompts.py --intro-only
```

できたプロンプトを、1つずつAIに投げます。**エディタは使いません。**

### 1. プロンプトをクリップボードにコピー

```bash
pbcopy < prompts_out/batch1_run1.txt
```

これでコピー済みです。ファイルを開く必要はありません。

### 2. ChatGPT か Claude の「新しいチャット」に ⌘V で貼って送信

### 3. 返答の「コピー」ボタンを押す

### 4. クリップボードをファイルに保存

```bash
pbpaste > responses/batch1_run1.txt
```

ファイルが無くても、このコマンドが作ってくれます。

### 5. 残りも同じように繰り返す

`batch1_run2`, `batch1_run3`, … とファイル名を変えるだけです。

> **毎回「新しいチャット」で実行してください。** 同じ会話の中で繰り返すと、
> AIが前の答えを見て同じことを言うので、ブレを測る意味がなくなります。
>
> 答えの保存は、JSONの部分だけ抜き出さなくて大丈夫です。
> AIの返答をまるごと貼り付ければ、こちらで読み取ります。

> **`open -e` は存在しないファイルを開けません。** 新規作成したいときは
> 上の `pbpaste >` を使うか、先に `touch responses/batch1_run1.txt` してください。

## STEP 4 — 表現ゆれをまとめる(30分)

「やらないことを決める」「捨てる勇気を持つ」「選択と集中」がバラバラに並んでいるので、
同じ意味のものをまとめます。

まず一覧を出します。

```bash
python3 aggregate.py --list-claims > claims.txt
open -e claims.txt
```

`prompts.md` の【名寄せプロンプト】をAIに貼り、続けて `claims.txt` の中身を貼ります。
返ってきた対応表を `canonical.json` として保存します。

```json
{
  "捨てる勇気を持つ": "やらないことを決める",
  "選択と集中": "やらないことを決める"
}
```

> **ここは必ず自分の目で確認してください。** 別物が同じ扱いになっていると結論が変わります。
> 特に「早起きする」と「朝に重要な仕事をする」のような、近いけど別物に注意。
>
> 面倒なら、このSTEPは飛ばしても集計は動きます(数字の精度は少し落ちます)。

- **`video_numbers.py`** — 動画に貼るための数字

## STEP 6 — 動画に反映する

`report.md` と `video_numbers.py` の中身を私に見せてください。
台本の数字・グラフ・セリフを実データに合わせて書き換えて、動画をビルドし直します。

自分でやる場合は `video-prototype/build_video.py` の `SCENES` の中の数字を、
`video_numbers.py` の値に置き換えて、`WATERMARK = ""` にしてからビルドしてください。

## 集計の途中で「この本は対象外だった」と気づいたら

idは**絶対に振り直さない**こと。`responses/` の答えはidで対応しているので、
振り直すと全部ずれる。外すだけなら専用のスクリプトを使う。

```bash
python3 drop_books.py b02 b05     # books.csv から外す(控えは books_dropped.csv)
python3 aggregate.py              # 集計し直す
```

AIに投げ直す必要はない。対象から外れた本の答えは、読まれないだけ。
